# Catch the Turtle Game

A simple Catch the Turtle game built with Python using the Turtle graphics library.

The goal of the game is to click the turtle as many times as possible before the timer runs out.

# How to Play

- Run the Python file.
- A turtle will appear randomly on the screen.
- Click the turtle to earn points.
- Each successful click increases your score by 1.
- You have 10 seconds to get the highest score possible.
- When the timer reaches 0, the game ends.

# Features

- Random turtle positions
- Score tracking
- 10-second countdown timer
- Click detection
- Game Over screen
- Simple graphical interface using Python Turtle

# Technologies

- Python
- Turtle
- Random

# How to Run

Make sure Python is installed on your computer.

Clone the repository:

git clone https://github.com/bejnasmin/Catch-the-Turtle-.git

Open the project folder:

cd Catch-the-Turtle-

Run the Python file:

python3 main.py
